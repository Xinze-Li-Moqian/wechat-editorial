# 资料与来源

新闻先核对官网公告、论文及原始代码。记录事件发生日期与文章发布日期；在 JSON 的 sources 中保存完整 URL。

“最大”“首次”“已经完成”等说法要有范围和出处。机构自己的声明用明确归属表达，不把它写成经过独立复核的结论。比较代码量时说明统计对象，简短保留影响比较的口径，不让注释占据正文。

数学论断核对论文中的定义、假设、定理与注释。形式化源码应定位到固定 commit 或版本，记录文件名及行号，区分真实源码和说明性伪代码。

配图记录来源、页面或图号；仓库示例和正式文章素材分开管理。第三方论文截图不要默认作为通用设计素材提交。

文末列出支持正文的具体资料。生成器默认不把来源 URL 变成超链接：曾遇到公众号拒绝非自身域名链接的情况。用户需要完整 URL 时可直接作为可见文字写入来源标题。
